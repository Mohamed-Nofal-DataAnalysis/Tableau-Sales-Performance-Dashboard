# 📊 Sales Performance Dashboard – Tableau

This project presents an interactive **Sales Performance Dashboard** built using **Tableau**, designed to analyze key business metrics including Sales, Profit, Quantity, Discounts, Product trends, and Geographic performance across U.S. states.

---

## 🚀 Project Overview

The dashboard provides a complete view of the company’s sales performance by visualizing:

- Total Sales, Profit, Quantity, and Average Discount  
- Top 10 Selling Products  
- Bottom 10 Products by Sales  
- Total Sales distribution by U.S. States  
- Sales breakdown by Segment (Consumer – Corporate – Home Office)  
- Sales percentage by Region (West – East – Central – South)

This Tableau visualization helps decision-makers quickly understand performance trends and identify improvement areas.

---

## 🗂️ Dataset Information

The dashboard is built on a standard **Superstore Sales Dataset**, including:

- Orders data  
- Products data  
- Customer segments  
- U.S. state-level geographic data
